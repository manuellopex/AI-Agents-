# Referencias de concept art

Coloca aquí los concept arts de los personajes (PNG/JPG):

- `mael_*.png` — Mael Veyra
- `oryn_*.png` — Oryn
- `elaria_*.png` — Elaria del Alba
- `liora_*.png` — Liora
- `varkon_*.png` — Varkon
- `seralya_*.png` — Seralya

Estas imágenes son la referencia principal de estilo, proporciones,
colores, materiales, silueta y personalidad para los modelos finales.
Los proxies generados por `CharacterPrefabBuilder` aproximan la paleta y
la silueta; el artista 3D debe usar estas referencias para la escultura
final (ver `Assets/Characters/Character_Art_Implementation_Guide.md`).
