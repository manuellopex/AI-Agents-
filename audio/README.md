# Música del juego

**Sube aquí tu música** y el juego la usa automáticamente:

- `music.mp3` — tema principal (se reproduce en bucle al darle a Jugar).
  Si el archivo no existe, suena la melodía sintetizada placeholder.

## Cómo subirla

1. Genera o consigue el tema (ver abajo), expórtalo como **MP3** (128-192
   kbps es suficiente; ideal < 4 MB para que cargue rápido en móvil).
2. Súbelo a esta carpeta con el nombre exacto `music.mp3`:
   - Desde GitHub web: Add file → Upload files en
     `public/audio/` de la rama del juego, o
   - dímelo a mí y lo integro.
3. Commit → en el siguiente deploy suena en el juego.

## Dónde conseguir música

- **IA**: [Suno](https://suno.com) o [Udio](https://udio.com) — pídeles
  "tropical adventure game music, loop, orchestral ukulele steel drums,
  no vocals" y exporta el MP3. Revisa la licencia de tu plan para uso
  comercial.
- **Libre de derechos**: Pixabay Music, FreePD, Kevin MacLeod
  (incompetech, CC-BY con crédito).

Consejo: que el tema esté pensado para **loop** (sin final abrupto).
